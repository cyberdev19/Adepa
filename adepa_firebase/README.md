# Adepa 🇬🇭 — Firebase Edition
> Anonymous social app for Ghanaians · Flutter + Firebase

---

## Architecture

```
Flutter App
    │
    ├── Firebase Auth       → Anonymous sign-in (no email/password needed)
    ├── Cloud Firestore     → Real-time posts, comments, reactions, votes
    └── Firebase Messaging  → Push notifications for new posts
```

## Firestore Data Model

```
posts/
  {postId}/
    text          : string
    tag           : string  (accra | gossip | football | politics | food | campus)
    colorHex      : string  (#006B3F etc.)
    createdAt     : timestamp
    votes         : number
    commentCount  : number
    reactions     : map     { "🔥": 12, "😂": 5 }
    authorId      : string  (anonymous UID)

    comments/
      {commentId}/
        text      : string
        colorHex  : string
        createdAt : timestamp
        authorId  : string

votes/
  {uid}_{postId}/
    vote          : number  (-1, 0, or 1)
    postId        : string
    uid           : string
```

## Setup Guide

### Step 1 — Create a Firebase project

1. Go to https://console.firebase.google.com
2. Click **Add project** → name it `adepa`
3. Disable Google Analytics (optional) → **Create project**

---

### Step 2 — Enable Firebase services

**Authentication:**
1. Console → **Authentication** → Get started
2. **Sign-in method** tab → Enable **Anonymous** → Save

**Firestore:**
1. Console → **Firestore Database** → Create database
2. Start in **production mode** → choose a region (e.g. `europe-west1` for low latency from Ghana)
3. After creation, go to **Rules** tab and paste the contents of `firestore.rules`

**Cloud Messaging (push notifications):**
- Already enabled by default — no extra steps needed for basic setup

---

### Step 3 — Connect Flutter to Firebase

Install the FlutterFire CLI:
```bash
dart pub global activate flutterfire_cli
```

In the project root, run:
```bash
flutterfire configure
```

- Select your `adepa` Firebase project
- Select platforms: **Android**, **iOS** (and Web if needed)
- This auto-generates `lib/firebase_options.dart` ✅

---

### Step 4 — Android setup

1. In the Firebase console → Project settings → Add Android app
   - Package name: `com.adepa.app` (or whatever is in your `android/app/build.gradle`)
2. Download `google-services.json` → place in `android/app/`
3. In `android/build.gradle` add:
   ```groovy
   dependencies {
     classpath 'com.google.gms:google-services:4.4.0'
   }
   ```
4. In `android/app/build.gradle` add at the bottom:
   ```groovy
   apply plugin: 'com.google.gms.google-services'
   ```

---

### Step 5 — iOS setup

1. In the Firebase console → Project settings → Add iOS app
   - Bundle ID: matches your Xcode project (e.g. `com.adepa.app`)
2. Download `GoogleService-Info.plist` → drag into `ios/Runner/` in Xcode
3. For push notifications: enable **Push Notifications** capability in Xcode
4. Upload your APNs key/certificate in Firebase → Project Settings → Cloud Messaging

---

### Step 6 — Run the app

```bash
flutter pub get
flutter run
```

### Build APK
```bash
flutter build apk --release
```

### Build iOS
```bash
flutter build ios --release
```

## Features
| Feature | Implementation |
|--------|---------------|
| Anonymous identity | Firebase Auth anonymous sign-in, persists across sessions |
| Real-time feed | `StreamBuilder` on Firestore `postsStream()` |
| Real-time comments | `StreamBuilder` on `commentsStream(postId)` |
| Voting | Firestore transaction — prevents duplicate votes per user |
| Emoji reactions | Firestore field increment on `reactions.{emoji}` |
| Push notifications | FCM topic subscription `ghana_posts` |
| Security | Firestore rules block editing text, only allow vote/reaction updates |
